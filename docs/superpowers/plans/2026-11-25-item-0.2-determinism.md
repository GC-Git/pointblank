# Item 0.2: Deterministic Clock and RNG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fixed-timestep world loop, one seeded RNG, a stable world state hash, and a test that keeps non-deterministic APIs out of `Sim`.

**Architecture:** `src/Sim` gets four small units: `Fixed` (Q31.32 number), `SimRng` (PCG32), `StateHasher` (FNV-1a 64 over little-endian bytes) and `World` (tick loop over registered systems and scheduled inputs). `tests/Sim.Tests` gets a source-text scan of `src/Sim`.

**Tech Stack:** C# / .NET 8 target, xUnit, no new packages.

**Spec:** `docs/superpowers/specs/2026-11-25-pointblank-vision-design.md` §8, §9; `docs/checklist.md` item 0.2.

## Global Constraints

- `Sim` never references Godot and gets no new package references.
- Same seed and same orders give the same battle: no wall-clock time, no unseeded randomness, no floating point.
- 10 ticks per simulated second.
- No hard-coded historical numbers (this item has none; no new placeholders).
- No `GetHashCode()` / `HashCode` for the state hash.

## Decisions

- **Number type:** Q31.32 in a `long`. 16.16 tops out at 32767, so a squared distance of 182 m would overflow. `Int128` intermediates make multiply and divide exact.
- **Overflow:** every operation throws `OverflowException`. No wrapping, no saturation.
- **Rounding:** multiply, divide, `FromRatio` and `ToInt` truncate toward zero, so `(-a)/b == -(a/b)`. `Sqrt` floors.
- **Trig, Abs, Min, Max:** not in this item.
- **Pending inputs are not hashed.** They belong to the replay (item 0.3), not to the world state.
- **Allow list for the scan:** empty. Neither `Fixed` nor `SimRng` needs a banned API, so none is exempt.

## Review Focus

- A product or quotient too big for `Fixed`: throws, never wraps (Task 1).
- `NextInt` with an empty range, or the whole `int` range: throws / works (Task 2).
- Two values hashed in swapped order: different hash (Task 3).
- An input scheduled for a tick that has already run: throws, never silently dropped (Task 4).
- `var x = Math.Sqrt(2)` with no `double` keyword in sight: the scan still fails (Task 5).
