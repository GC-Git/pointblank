# Item 0.4: data files with sources (plan)

**Goal:** JSON data files under `data/` (one per category) with a loader that rejects any
value lacking a source tag, a placeholder report, and a disabled-by-default zero-placeholder test.

**Design**
- Loader lives in `src/Sim/Data` (namespace `PointBlank.Sim.Data`), not a separate project: it
  is pure integer code, so the banned-API scanner covers it for free, and `game/` and the
  runner already reference `Sim`.
- File shape: `{"table": "weapons", "entries": [{"id": "...", "values": {"name": {"value", "unit", "source"}}}]}`.
  Tables: units, weapons, ammo, materials, organisation (file name = table name). Each table
  lists required value names; unit is a required string (`text` for non-numeric values).
- `source` is `{"kind":"reference","ref":...}`, `{"kind":"estimated","reasoning":...}` or
  `{"kind":"placeholder","note":...}`. Missing or malformed source throws `DataException`.
- Numbers parse from decimal text or JSON integers straight to `Fixed` (integer arithmetic,
  no `double`). Anything else (exponents, more than 15 digits) is rejected.
- `PlaceholderReport` counts by table, in fixed table order; `runner --data-report [dir]`
  prints it deterministically.
- `NoPlaceholdersTests` is skipped by default; item 7.7 sets one constant to `null`.
