# Item 0.3 Headless Battle Runner and Replays Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans, inline in this
> session (set by the session brief). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `runner --scenario X --seeds 1..100 --out stats.json` with byte-identical output,
and replay files that re-run to the same final hash.

**Architecture:** The replay model, its JSON form and the run/replay logic live in `Sim`
(`src/Sim/Replays/`), so the game can save the same files later. A new console project
`tools/Runner` holds the scenarios and the CLI. `Sim.Tests` references both.

**Tech Stack:** C# / net8.0, System.Text.Json (in the framework, no new packages), xUnit.

**Spec:** `docs/superpowers/specs/2026-11-25-pointblank-vision-design.md` §8

## Global Constraints

- `Sim` never references Godot and stays deterministic; the banned-API scan must pass
  with its allow list still empty.
- Replay = seed + map + forces + timestamped orders, with a schema version.
- `stats.json`: fixed key order, invariant culture, LF newlines, UTF-8 without BOM, no
  timestamps, paths or machine data. Wall-clock time goes to the console only.
- No new data values or placeholders.
- `game/` is untouched; Godot must still build the solution.

## Review Focus

- A replay order at a tick outside the battle (negative, or >= `ticks`) would be silently
  skipped or throw deep in `World`: reject it up front.
- A replay for an unknown scenario, or another map/force version: clear error, no run.
- A truncated or hand-edited replay (bad JSON, missing field, wrong type, bad order
  type or arguments): `FormatException` / exit 2, never a stack trace.
- A bad command line (reversed or non-numeric seed range, missing or unknown option):
  exit 2 with a message, and no output file.
- A machine with a comma decimal culture: identical bytes.

## Interfaces

`src/Sim/Replays/`, namespace `PointBlank.Sim.Replays`:

```csharp
public sealed record ContentRef(string Id, int Version);
public sealed record ReplayOrder(long Tick, string Type, IReadOnlyList<long> Args);
public sealed record Replay(string Scenario, ulong Seed, ContentRef Map,
    IReadOnlyList<ContentRef> Forces, int Ticks, IReadOnlyList<ReplayOrder> Orders,
    ulong FinalHash);
public sealed record Metric(string Name, Fixed Value);
public interface IScenario
{
    string Id { get; }
    ContentRef Map { get; }
    IReadOnlyList<ContentRef> Forces { get; }
    int Ticks { get; }
    IReadOnlyList<ReplayOrder> ScriptedOrders { get; }
    World CreateWorld(ulong seed);
    ISimInput CreateInput(ReplayOrder order);   // FormatException on a bad order
    IReadOnlyList<Metric> Measure(World world);
}
public sealed record BattleResult(World World, Replay Replay);
public static class Battle
{
    public static BattleResult Run(IScenario scenario, ulong seed);   // scripted orders
    public static World Play(IScenario scenario, Replay replay);      // replay's orders
}
public static class ReplayJson
{
    public const int Version = 1;
    public static string Write(Replay replay);
    public static Replay Read(string json);     // FormatException on anything invalid
}
```

Replay JSON, in this key order (`finalHash` is 16 lower-case hex digits):

```json
{ "version": 1, "scenario": "wander", "seed": 1,
  "map": { "id": "open-field", "version": 1 },
  "forces": [ { "id": "wanderers", "version": 1 } ],
  "ticks": 1000,
  "orders": [ { "tick": 0, "type": "nudge", "args": [0, 10] } ],
  "finalHash": "0123456789abcdef" }
```

`tools/Runner/`, namespace `PointBlank.Runner`:

- `Scenarios/WanderScenario.cs` (id `wander`, 1000 ticks, order `nudge [index 0..7,
  distance -1000..1000]`, metrics `travelled`, `meanX`, `meanY`), a copy of the test
  system in `DeterminismTests`, which stays as it is.
- `Scenarios/ScenarioCatalog.cs`: `static IScenario? Find(string id)`, `static
  IReadOnlyList<string> Ids`.
- `SeedRange.cs`: `static bool TryParse(string text, out ulong first, out ulong last)`;
  accepts `N` or `A..B` with `A <= B`, at most 100,000 seeds.
- `StatsJson.cs`: `static string Write(IScenario scenario, IReadOnlyList<BattleResult>
  results)`. Layout: `version`, `scenario`, `ticks`, `runs[]` (`seed`, `finalHash`,
  `metrics{}`), `summary{ name: { min, max, mean } }`.
- `RunnerApp.cs`: `static int Run(string[] args, TextWriter output, TextWriter error)`.
  Modes: `--scenario X --seeds R --out F [--replays DIR]` (saves
  `DIR/<scenario>-seed<N>.replay.json`) and `--replay F` (re-run and compare). Exit 0
  success, 1 hash mismatch, 2 usage, input or file error.
- `Program.cs`: calls `RunnerApp.Run`.
